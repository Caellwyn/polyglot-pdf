Installation

  1. Make sure the dev server is running: 
    cd frontend && npm run dev
  2. Drag this button to your bookmarks bar:
🎤 Voice Filler (LOCAL)
  1. Navigate to any web form
  2. Click the bookmarklet in your bookmarks bar
  3. Click "Connect" and start speaking!

Testing Barge-In

  1. Start a voice session on a form
  2. Let Gemini start talking (TTS playback)
  3. Interrupt mid-sentence by speaking
  4. Open Console (F12) and watch for: 
    [VFF Connection] 📤 Sending activity_start to Gemini
[VFF Connection] 🛑 BARGE-IN DETECTED!
[VFF Audio] 🛑 Flushing audio queue - X sources
[VFF Audio] 🚫 Playback blocked - dropping audio chunk (5-10x)
[VFF Connection] 📤 Sending activity_end to Gemini
[VFF Audio] ✅ Playback RESUMED

Expected Behavior

  • ✅ Gemini stops talking instantly when you interrupt
  • ✅ Gemini stays silent while you speak
  • ✅ No overlapping audio
  • ✅ No hallucinated field fills during barge-in
  • ✅ Gemini responds normally after you finish

Troubleshooting

If bookmarklet doesn't load:
  1. Check dev server is running: npm run dev
  2. Verify server is on http://localhost:5174
  3. Check console for CORS errors
  4. Rebuild bookmarklet: npm run build:bookmarklet
Cache Buster: The bookmarklet includes ?t='+Date.now() to bypass browser cache and always load the latest version.

Deployment

When ready for production, use install-bookmarklet-production.html which loads from the CDN.
