Mitigated: measured, real, gemini-2.5-flash-native-audio, full I-90 form, 113 questions, happy path. Naive baseline: derived, not measured -- no real "everything off" run exists at full-form scale. Built from real building blocks: (1) the actual per-question spoken content (voice in/out, text out) from the same session, so the conversation itself is identical between the two lines; (2) a full-form (132-field), non-mitigated system instruction size fit from real measured full-SI-vs-field-count data across 12 sections of a different schema (R-squared = 0.998: chars = 117.5 x fields + 3235 fixed overhead), applied to the I-90's 132 fields => ~4,687 tokens, re-sent every turn with the full conversation history accumulating without limit; (3) the same real per-token rates ($0.50 / $3.00 / $2.00 / $12.00 per 1M tokens for text-in / voice-in / text-out / voice-out). See README.md and data/naive_vs_mitigated_cost_curve.csv in this folder for the full methodology and underlying numbers.
