## Trigger

After PR #57 (a single-file doctrine reword) took ~25 orchestrator turns — ~9 just
for the `/closeout` ceremony, almost all on Opus — the maintainer asked whether the
mechanical busywork could be scripted or delegated to a cheaper model. A turn audit
showed ~half the closeout turns were pure git/bead mechanics with zero judgment.
Filed as `polyglot-pdf-hrn.13` (design bead); planned and approved before building.

## What shipped

Two layers (maintainer chose "both now", one-shot script with `--dry-run`, no A/B
arm yet, two-call bead close):

- **`scripts/closeout_finish.py`** — one-shot glue for Steps 5–8.5: commit staged
  work → rebase → push → open PR (→ for review-worthy: post the `@copilot please
  review` comment, capture its `created_at`, PRINT the watch command) → record the
  telemetry row (warn-only) → optionally `--close-beads`. Resolves `$R`/`$WT`/`$PY`
  **internally** (imports `resolve_roots`/`venv_python` from `closeout_prep.py` —
  one source of truth for the worktree traps). `--dry-run` prints the fully-resolved
  plan with **zero** side effects. Exit codes 0/1/2/4 (**4 = rebase conflict**:
  aborts the rebase, leaves the branch clean, hands resolution back to the
  orchestrator). All git/gh/bd/ledger calls route through a single `_run` seam.
- **`.claude/agents/closeout-runner.md`** — a Haiku mechanical driver (mirrors the
  `fresh-eyes-reviewer` agent convention): runs prep, writes the already-composed
  journal entry once, runs `closeout_finish.py`, relays the RESULT block. Renders
  **no verdicts**; STOPS back to the orchestrator at every judgment point (prep
  ATTENTION, rebase conflict, tooling error, missing brief input). The standing
  rule: "a cheap model guessing at a judgment call is worse than a clean stop."
- **SKILL.md** — new "Mechanical handoff" section codifying the judgment-vs-glue
  split and the delegation flow; documents `closeout_finish.py` + the `--dry-run`
  preview; **fixes the journal `--print` dance** (write the filled entry once, not
  the empty-then-Read-then-Edit 3-turn waste). Raw hand-run forms kept as fallback.
- **Tests** — `tests/test_closeout_finish.py` (17 cases): CLI gate, the headline
  **dry-run-makes-zero-mutating-calls** guard, every-git-call-is-`git -C <WT>`,
  no-`git add`, review-worthy opens+triggers+captures-TS, trigger-never-in-body,
  bare-`--base`-name, skip-review-no-trigger, rebase-conflict→exit 4, telemetry
  warn-only, `--close-beads` gating, branch-mismatch→exit 2. `test_closeout_skill.py`
  extended to assert the new script + the handoff/`--dry-run` docs.

**Decisions made autonomously** (defended in the merge ping): import (not copy) the
root helpers; script-test stays in `tests/` per existing convention (a pre-existing
coverage nuance, not introduced here); the two-call bead-close split. **Escalated to
the maintainer:** the merge-trigger idea (needs CI + a Dolt-remote credential) →
filed as `polyglot-pdf-hrn.14`, blocked-by this bead; and the bead-close-timing
ergonomics (chose two-call over a blocking script after laying out the risks).

## Lessons

- **The scar-tissue traps the script encapsulates, I tripped while building it:** I
  first wrote `closeout_finish.py` to the *main repo* path instead of the worktree
  (CLAUDE.md trap #3) and had to move it. Strong evidence that encapsulating the
  `$R`/`$WT` resolution in a script — so neither Opus nor Haiku re-derives it — is
  the right call; the trap is live even for the model writing the fix.
- **`gh pr create --base` wants the bare branch name, not `origin/dev`.** The
  `--base` default (`origin/dev`) is right for the rebase ref but had to be reduced
  to `dev` for `gh`. Caught by reading the existing SKILL invocation, not by a test
  first — added a regression test after.
- **`--dry-run` is the de-risking tool for metered/irreversible glue.** Being able
  to print the fully-substituted plan (and shell the ledger's own `--dry-run`)
  proved path resolution and the no-side-effects promise before any real PR.
