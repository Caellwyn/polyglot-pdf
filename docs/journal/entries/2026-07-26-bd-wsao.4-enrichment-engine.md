# Enrichment engine dry-run: born containment-clean in 3 rounds (bd wsao.4)

## What shipped

`scripts/authoring/enrich_instructions.py` -- the sprint-16 guidance engine,
dry-run only (proposals JSON + report; kit writes are wsao.5's job). Reads a
kit's schema + booklet, renders `guidance_contract.CONTRACT_TEXT` verbatim
into the prompt (one module shared with lint + the future judge), chunks
askable fields (~40/call), and emits per-field
{instructions, details, format_hint} + one form-level details block through
`llm_providers.resolve_json_runner` -- new generic JSON runners that reuse
the CLI scratch-file + Vertex-default Gemini transports WITHOUT touching the
graded schema-extraction path.

## The 3-round loop (each round killed a failure CLASS, permanently)

w7, default Claude CLI: 19 findings -> 12 -> 6 -> **1** (the aggregate
coverage worklist indicator only; zero defect-class findings).

1. **Pinned-normalization additions** (r1->r2): bullet glyphs fold to `-`
   and slash-wraps join (`citizen/\nresident`) -- PDF extraction artifacts,
   same class as dehyphenation, NOT a loosening toward paraphrase. Plus
   `clean_booklet_furniture`: the raw stream interleaves `CAUTION !` sidebar
   labels and page footers MID-SENTENCE; the cleaner now feeds BOTH the
   model and the baked floor, so containment is consistent by construction.
2. **Paragraph contiguity** (r2->r3): the model legitimately skipped
   tangential `Note.` blocks but glued non-adjacent sentences into one
   paragraph. The prompt now pins the check's actual unit: one paragraph =
   one unbroken source span; skips happen only at blank lines.
3. The check also caught one GENUINE elision (list items a/b/c dropped
   inside Exception 2) -- the misleading-by-omission class, working exactly
   as the plan intended.

## Results

- Claude CLI (authoring default): 49/57 covered (86%), details on 35
  fields, 5,096-char form_details, containment-clean. The 8 uncovered
  fields are honest empties (empty-beats-filler).
- Gemini flash-lite (provider-duality check): full parse, 57/57 coverage,
  10 quality findings -- the floor tier fills everything but writes filler;
  opus stays the default and the wsao.5 judge handles residuals. ~$0.01.
- Content spot-check: reason_a instructions correctly synthesize the box-h
  interlock + SSN-first caveat, speakably; details verbatim under headings;
  form_details opens with What's an ITIN / Purpose of Form.

## Scar / notes

- `maxOutputTokens=65536` 400s on Vertex flash-lite -- the documented limit
  is EXCLUSIVE there; use 65535.
- The Claude CLI envelope's `usage.input_tokens` is meaningless for cost on
  subscription auth (reported 4); treat `cost_usd_equiv` as notional.
- "Lint-clean" in this epic's gates = zero DEFECT-class findings; the
  aggregate coverage indicator fires by design whenever any askable field
  is honestly empty.
