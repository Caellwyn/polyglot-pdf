## Trigger

Follow-on from the G2 cost spike (bd jnjj.6). After G2 came back NO-GO on the JIT
manifest swap, a maintainer design discussion (2026-06-16) reframed the whole A
pillar: instead of only shrinking the per-turn system instruction (SI) via a
manifest, model the system as a **principal/assistant** pair -- a thin live voice
model (the principal) that carries only the current question, plus a cheap fast
"secretary" model that holds the form catalog + client values and answers the
principal's prose navigation queries. This entry captures the planning output and
a correction to a cost claim I got wrong mid-discussion.

## Lessons

- **The expensive cost finding was nearly lost in a spike doc.** "On 2.5 the
  per-turn SI is 95-98% of cost, audio is negligible" cost real time+money to
  establish (wyhh/jnjj.6) but lived only in `scripts/spikes/*_findings.md`. I
  asserted the OPPOSITE from pricing-table intuition mid-discussion (audio
  dominates) and was corrected. The durable fix is to put expensive, counter
  intuitive measured facts in a tier-2 MANDATORY-read doc with a trigger, not just
  a findings file -- which is what this PR does. Scar: a fact that cost a sprint to
  learn must be repo-discoverable at the point of use, not buried.
- **The demo schema is a trap for measurement.** It is near-empty of the nested
  `help` block real forms carry, which both starved the JIT cost runs and hid the
  help.instructions bug (jnjj.23). All forward voice/cost/secretary measurement
  must use `form-kits/i-90/schema.json`, not `adult_intake_demo_schema.json`.
- **Push richness to the cheap tier, keep the expensive tier thin.** The design
  principle that fell out of the secretary discussion: the principal holds
  conversation + one current question; the full form catalog + values live with
  the cheap model and the client. The secretary's payload is RICHER than instinct
  suggests (it needs help.instructions to disambiguate ambiguous fields) -- but
  that richness is cheap because it is not in the per-turn live-model SI.
