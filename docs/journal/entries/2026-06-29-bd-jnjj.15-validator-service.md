## Trigger

Pillar B of the SI-reduction epic (`polyglot-pdf-jnjj`). The live voice model
fills the form field-by-field; field-level validation
(`backend/utils/field_validator.py`) checks one value against its own schema
constraints but is structurally blind to CROSS-field contradictions -- a ZIP that
does not match the stated state, a US state filled alongside a foreign country, a
future-dated date of birth. The G1 keystone probe (jnjj.5) measured that the cheap
`gemini-2.5-flash-lite` text model catches those at recall 0.853 / precision 1.000
on a synthetic I-90 corpus -- precision 1.000 means it adds zero false positives,
so it is safe to run as an ADDITIVE second-pass net. B3 (this bead) builds the
service that does that: render the client's form state into the minimal validator
payload, ask flash-lite for the named contradiction classes, parse the verdict.

Post-2026-06-17 rescope (recorded in the bead): Pillar B is defense-in-depth, NOT
a replacement -- the in-system-instruction ADDRESS CONSISTENCY prose STAYS as the
primary check; this validator is the extra net at section/form boundaries.

## What shipped

`backend/services/validator_service.py` (new) -- `ValidatorService` +
`render_validator_payload` helper:

- **`render_validator_payload(fields, today=...)`** turns the contract-2
  client-state payload (a list of `{field_id, name, value, steered}`) into the
  `{stable_prefix, fresh_tail, field_count}` dict the `TextAIGemini.validate()`
  adapter already expects. The contradiction system-instruction goes in the
  value-free `stable_prefix` (the implicit-cache target); the form-state JSON rides
  the `fresh_tail`. `field_count` is PII-safe telemetry only.
- **`CONTRADICTION_SI`** reproduces the `FLASH_LITE_PROMPT` the G1 probe
  (`backend/scripts/probe_g1_contradiction_recall.py`) pinned and scored GO, MINUS
  the trailing `FIELDS:\n{state}` (the state moved to the fresh tail). A test
  asserts the deployed SI equals the probe prompt head, so the validator that ships
  is the one the gate measured -- they cannot silently drift apart.
- **`today` is an injectable parameter** (defaults to the real UTC date). The
  date-sanity checks ("a DOB must not be in the future") need an anchor; making it
  a parameter keeps tests deterministic and avoids calling `datetime.now()` at
  module import (which would also be unstable across a session and defeat the
  byte-stable cache prefix).
- **`ValidatorService.validate(fields, today=...)`** renders, calls
  `ITextAI.validate()`, sanitizes the returned conflicts to the contract-1 shape
  (each kept conflict has a non-empty `field_ids` list of strings + a string
  `reason`; a single field id is valid -- a future-DOB is a single-field semantic
  error), and returns `{"conflicts": [...]}`. A malformed individual conflict is
  DROPPED, not raised.
- **Fail-OPEN (contract 6).** Any non-verdict outcome -- the adapter's own
  fail-open, a raising adapter, a bad-shape verdict, or a render error -- returns
  the all-clear `{"conflicts": []}` and logs a degraded check. A voice UX must
  never stall on an auxiliary text-model outage; a missed contradiction is a soft
  degradation (field-level validation and the user's own confirmation still stand),
  a blocked advance is a hard UX failure. The bead-recorded consequence: post-B1
  there is no inline fallback, so a sustained flash-lite outage silently disables
  detection -- accepted and recorded.
- **PII-safe logging.** The service logs only field/conflict counts and exception
  types -- never the payload, field values, or the verdict `reason` text. The
  `reason` may quote values; it rides the in-band steering message to the Live
  model (bead B5), which is not a log sink.

`backend/tests/test_validator_service.py` (new) -- 20 tests covering all three
exit criteria: the three contradiction classes on the G1 corpus fixtures (with a
payload-reading oracle stub, so the test stays deterministic without live Gemini
yet still proves the service renders the values into the payload and faithfully
returns the model's verdict), the empty-list all-clear, the payload-render shape,
the SI-matches-probe assertion, the conflict sanitizer, and the full fail-OPEN
matrix (raising adapter, adapter fail-open, six bad verdict shapes, malformed
conflict drop). Two PII tests assert no value or reason text reaches any log event.

**Scope boundary.** The service is standalone -- NO dependency-injection wiring and
NO WebSocket-boundary plumbing was added. Wiring it to the proactive
section-complete / form-complete events (contract 4) and the steering injection
(contract 3) is explicitly B4 (jnjj.16) + B5 (jnjj.17); adding it here would reach
beyond this bead.

**Assess (pre-PR).** Exit-criteria rubric scored all-PASS (scorecard in the PR
body). Fresh-eyes adversarial loop: see the merge ping / PR for the round outcome.

## Lessons

- The B-pillar adapter (`TextAIGemini.validate`) consumes a `{stable_prefix,
  fresh_tail, field_count}` dict, NOT the raw contract-2 `{fields: [...]}` payload.
  The render-into-request split is the SERVICE's job (B3), mirroring how the
  secretary's `ask()` path splits a stable catalog prefix from an append-only
  values tail. The contract doc's "minimal client-state payload" (contract 2) is
  the service's INPUT; the adapter's payload is a different, lower-level shape.
- Keep a deployed prompt pinned to the prompt a gate measured with a test that
  asserts equality. The G1 GO verdict is only meaningful if the production
  validator uses the prompt that was scored; an equality test makes that invariant
  load-bearing instead of a comment.
