## Trigger

R2 of the harness-autonomy epic (`polyglot-pdf-h2r`), plan of record
[`sprint_1_harness-tuning_plan.md`](../../sprint_1_harness-tuning_plan.md) (R2).
A long orchestrator session auto-compacts near context-fill; each compaction is
lossy; a session that keeps claiming new beads across compactions degrades and
burns tokens re-deriving its own state. R2 makes the session **drain cleanly** --
stop claiming new work once it is winding down, finish (or split) what is in
flight, and let a fresh successor pick up from the tracker.

## What shipped

- **`scripts/drain_flag.py`** -- a two-hook mechanism. `PreCompact` (auto only)
  writes a session-scoped marker under `.beads/.runtime/` (gitignored); the
  post-compaction `SessionStart` (`source=compact`) reads it and prints the
  documented `hookSpecificOutput.additionalContext` JSON, surfacing a DRAIN
  directive to the first post-compaction turn. Manual `/compact` never drains.
- **`docs/doctrine/drain-handover.md`** -- the protocol as a **Case A-D bead-split
  decision tree** (nothing-in-flight / nearly-done / coherent-checkpoint-split /
  half-edited-defer), each branch grounded in existing `workflow.md` lifecycle +
  `planning.md` SPEAR rules. The maintainer-applied `settings.json` wiring is
  documented inline.
- **`tests/test_drain_flag.py`** -- 23 unit tests (marker raise/skip,
  directive surfacing + one-shot consume, session-scoping by id-or-transcript,
  stale sweep, robustness on malformed stdin).
- Cross-links in `CLAUDE.md`, `docs/INDEX.md`, `docs/doctrine/workflow.md`.

**Two design decisions worth recording:**

1. **The two-hook shape is forced, not chosen.** Verified against the Claude Code
   hooks docs: PreCompact stdout is NOT injected into the model's context (only a
   fixed set of hooks, SessionStart among them, can inject `additionalContext`).
   So PreCompact alone cannot tell the orchestrator to drain -- the marker file is
   the durable cross-hook signal and SessionStart(compact) is the context-facing
   half. Two undocumented gaps are handled defensively: the PreCompact `trigger`
   field is corroborated by the hook's `matcher: "auto"`; and because
   `session_id` stability across compaction is undocumented, a marker matches by
   `session_id` OR `transcript_path` (the latter is stable -- same conversation
   file).

2. **The tracker IS the handoff -- no side-channel note (maintainer direction).**
   The first implementation wrote a `handover-*.md` note file surfaced to the
   successor. The maintainer rejected a parallel handoff system: beads already
   holds the durable state, so a mid-bead drain must **split the bead** (close
   what shipped with rewritten exit criteria; file a remainder bead with its own
   criteria + carried-forward deps) rather than write a note. The note machinery
   (`cmd_handover`, `handover_path`, `_surface_handover_note`) was removed; the
   successor rehydrates purely from `bd ready`. Removing the note also dropped the
   allowlist line from the maintainer ask (no orchestrator-invoked subcommand
   remains).

**Deferred / out of scope:** successor auto-spawn stays conceptual
(bounded-pool/budget; 5-hour quota backstop), per the bead. Live auto-compaction
observation is deferred until the `settings.json` hooks are wired (the auto-mode
self-modification guard blocks the orchestrator from editing that file -- same
constraint hit before; left for the maintainer with the exact change documented).

## Lessons

- **PreCompact is not a context-facing hook.** Any "tell the model something at
  compaction" design needs the PreCompact-writes-marker -> SessionStart(compact)-
  injects-context two-step. Recorded here so the next person does not try to
  `print()` from PreCompact and wonder why nothing appears.
- **Worktree write-path scar bit again.** Mid-implementation, Write/Edit calls
  using main-repo absolute paths landed in the MAIN checkout (which also had
  unrelated dirty changes), not the worktree -- exactly CLAUDE.md scar #3's
  file-write half. Recovered by re-applying every change in the worktree on a
  clean `dev` base and surgically reverting main. Reinforces: in a worktree, give
  Write/Edit the `.claude/worktrees/<name>/` path, and verify `git -C <main>
  status` stays clean of your files.
