## What shipped

Three new backend spec suites (13 tests), each asserting a property that holds
regardless of how -- or whether -- the Gemini session is restarted at a section
boundary. None of them calls `switch_to_section` / `restart_gemini_session` /
`finalize` / `send_initiating_message` (verified by grep; the only references are
in docstrings that DOCUMENT the exclusion).

- **uov.10 (T2.3) one-adapter-per-WS isolation**
  (`backend/tests/unit/test_adapter_per_ws_isolation.py`, 4 tests): regression
  guard for the 1g6 shared-instance bug that routed tool calls to the wrong tab.
  Asserts `get_live_ai()` returns a fresh `LiveAIGemini` per call with a distinct
  `instance_id`, and `on_tool_call` set on one connection never cross-routes to
  another (including the order-dependent "B registers after A" case that was the
  original clobber). Pure per-connection adapter instancing; patches
  `_run_session_loop` to a no-op so `set_callbacks` does not spin a real session.
- **uov.8 (T2.1) stateless reconnect isolation**
  (`backend/tests/unit/test_stateless_reconnect_isolation.py`, 4 tests): asserts
  on the ABSENCE of server-side value state. `update_schema` drops
  `current_values` on the floor; no client value is recoverable off the service
  after a connect (checked against the full `vars(service)` blob, not one named
  attr), a simulated plain disconnect/reconnect leaves no residue, and the
  fields view derives from the schema only. Driven over a PLAIN reconnect, not a
  section switch -- so it FAILS if per-session field persistence is ever
  introduced, the exact regression the stateless invariant (scar #4) guards.
- **uov.11 (T2.4) model-conditional `_send_text_turn`**
  (`backend/tests/unit/test_send_text_turn_model_branch.py`, 5 tests): 3.1 family
  -> `send_realtime_input(text=)`; 2.5/other -> `send_client_content(turns,
  turn_complete)` (the 1007-trap guard). Exercises `_send_text_turn` DIRECTLY
  with a mocked session + swapped model name -- not the section re-prime path --
  because the model-family branch is a per-TURN decision, not per-session-
  lifecycle. Includes a precondition test pinning the `model_family` mapping, an
  unknown-model fallback case, and a same-adapter model-swap case mirroring the
  USE_PREMIUM_MODEL A/B toggle.

## Lessons

When a spec's TARGET code path is slated to change, scope the assertion to the
INVARIANT, not the mechanism: a stateless-reconnect spec that asserts "no field
state survives ANY reconnect" survives a reset rewrite, whereas one that drives
its assertion THROUGH `switch_to_section` would have to be rewritten the moment
that path changes. The grep-for-forbidden-symbols self-check
(`switch_to_section|restart_gemini_session|finalize|send_initiating_message`)
made the exclusion auditable rather than aspirational. Generalizes to any
test-writing against code with a known pending refactor.
