## Trigger

`bd polyglot-pdf-gfb.4`, the last open child of the docs-reorg epic
`polyglot-pdf-gfb`. Enforce the terminology canon (`docs/standards/terminology.md`,
`m3f`): rename the section-state holdouts mis-named `part` (they mean the current
**section** — the navigation unit — not the optional `FormPart` grouping). The
canon's acceptance allowed "manifest ambiguity resolved **or split out**."

## What shipped

**Internal section-state renames (behavior-preserving):**

- `backend/adapters/live_ai_gemini.py`: `self._current_part_id` →
  `self._current_section_id`; the `set_session_context()` parameter
  `current_part_id` → `current_section_id` (+ docstring). The token-log call site now
  reads `part_id=self._current_section_id` — the *value* is the section id; the
  `part_id=` kwarg name is the logger's (deferred) wire key.
- `backend/services/form_filling_service.py`: the matching `set_session_context(...)`
  call site (`current_part_id=None` → `current_section_id=None`).

Verified no other caller/reference remained (`set_session_context` has two callers;
the unit-test caller doesn't pass the section arg). Deterministic suite green.

**Scope split (per the canon):** the `part` holdouts that are **data-format keys**
were deliberately NOT renamed here, because renaming a key is a breaking format
change that must be sequenced against consumers — filed as `bd polyglot-pdf-zun`:

- `backend/utils/token_file_logger.py` — the `part_id` param + `"part_id"` payload
  key (the `token_usage.jsonl` log format; check any analysis/BigQuery sink first).
- `backend/services/manifest_service.py` + `frontend/.../manifestUtils.ts` — the
  `current_part`/`previous_parts` **WS-handshake** keys (must change both ends in
  lockstep). These hold section data despite the name (the canon documents this).

**Docs updated to current state:** `terminology.md` (internal holdouts now done →
only the wire-format remainder remains, → `zun`); `CLAUDE.md` scar-tissue #5 (same);

## Lessons

The `part_id=self._current_section_id` line is the seam where an internal rename
meets a deferred wire-format one: the kwarg name belongs to the logger's public
(deferred) param, so only the *value* could be renamed now. Splitting at the
data-format boundary — rename internals freely, sequence wire/log keys against their
consumers — is the right granularity for a "fix the naming drift" task and is now
encoded in `terminology.md` + the `zun` split. Ties into
[[verify-claims-against-code-not-brief]] (the bead's 2026-05-30 line refs had
drifted; re-grepped current code before touching).
