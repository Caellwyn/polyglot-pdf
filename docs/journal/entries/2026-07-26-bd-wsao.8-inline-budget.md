# 20k inline guidance budget + working ask-secretary hook + real cost (bd wsao.8)

## The decision this implements (maintainer, 2026-07-26)

Resolves the wsao.2 oversize question: per-field guidance rides INLINE while
the field is focused, up to a generous 20,000-character budget
(`guidance_contract.DETAILS_INLINE_MAX_CHARS`); the secretary holds the FULL
text (the wsao.1 whole-booklet floor). Oversize SOURCES are handled by
SELECTION + INDEX -- verbatim excerpts up to budget plus a one-line index of
dropped topics -- never summarization (bake-time rewriting of legal text) and
never blind truncation (the model must know what it is missing). Decided in
discussion; recorded on the bead.

## What shipped

- `guidance_contract`: the budget constant, `clamp_details_inline` (defensive
  render backstop: paragraph-boundary cut + topic index + "ask the
  secretary" pointer), `inline_injection_budget_tokens`.
- `manifest_service.get_field_guidance` clamps details at render.
- `derive_compression_window` gains `injection_budget_tokens`;
  `FormFillingService` computes it from the schema and threads it through
  `set_callbacks` -- THE fix for the wsao.2 1007 (a details-bearing
  initiating message used to exceed the assembled window before the session
  ever opened).
- SI: the DEEP QUESTIONS rule now names `ask_secretary` actionably, and a new
  INFORMATION-NEVER-ADVICE rule (maintainer directive): never tell the user
  what to enter or choose; only explain what the official instructions say.
- `ask_secretary` tool description gains use (3): official-guidance lookups
  from the booklet floor (name/id prohibition kept, bd 2af7).
- Lint `help-details-oversize` re-anchored to the 20k inline budget.

## Measured (live harness, w7 reason field)

- **W1**: the wsao.2 fatal case (13,467-char details inline) opens cleanly --
  derived window 8,425 = floor 4,460 + headroom 599 + injection budget 3,366
  (was ~6,400 -> 1007) -- and completes the full cycle. The model's deep
  answer is attributed information ("The instructions state that...").
- **W2**: on a floor-only field the model ACTUALLY CALLS ask_secretary
  (2.5s deadline -> pending -> async delivery from the catalog+floor ->
  voiced grounded answer). The wsao.2 says-but-never-calls gap is closed.
- **Cost** (session_cost_summary telemetry): W1 $0.0400 vs W2 $0.0244 on the
  identical scenario => worst-case inline details ~= $0.016/encounter, ~3x
  the $0.005 estimate (the block stays resident ~6 turns, not 2), same order
  of magnitude, paid per-visit, reclaimed by compression afterward.

## Scar / notes

- The window derivation is the load-bearing piece: without
  `injection_budget_tokens`, inline details of any real size kill the session
  AT ASSEMBLE with a misleading-looking Vertex 1007. Any future channel that
  injects large per-turn content must add its budget to the derivation.
- TaskStop on a backgrounded npx/vite does not kill the child listener --
  port 5174 stayed bound; reuse it or kill the node PID.
