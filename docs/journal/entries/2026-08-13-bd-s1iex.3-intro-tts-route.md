## Trigger

Sprint 20 stage 2 (epic `polyglot-pdf-s1iex`, plan
`docs/sprint_20_sol-intro-tts_plan.md`): the backend route that turns the
canonical 18-language intro script (merged in PR #584) into the audio clip the
client will play before Agree. Unblocked by the beads 1+2 merge; first
consumer of the `intro_script.json` store.

## What shipped

- **`POST /api/tts/intro`** in `backend/routes/tts_routes.py`, gated on the
  new `INTRO_TTS_ENABLED` flag (503 while dark; backend half of the epic's
  two-flag design). Keyed-route contract enforced at three layers: the wire
  `form_number` must be a key of `intro_tts.KNOWN_FORMS` (explicit table --
  kit ids do NOT map cleanly to spoken names: `f1040` -> "Form 1040",
  `w9-heldout` -> "Form W-9"), the agree label comes from
  `intro_agree_labels.json`, and the script text from `intro_script.json` --
  no caller-supplied string ever reaches synthesis on an endpoint with no
  rate limiting.
- **`backend/services/intro_tts.py`**: language resolution with English
  fallback (mirrors the shipped modal's own fallback), placeholder
  interpolation, in-process cache keyed `(language, form, script_hash)`,
  audio-bytes ETag, `script_version()` exposed for the acceptance record
  (bead `.7`), `asyncio.to_thread` loop discipline throughout.
- **Gain 0 dB, structurally**: `_synthesize_sync` grew an optional `gain_db`
  param (spell-back default unchanged -- `None` still applies the per-voice
  measured gain); the intro passes 0.0 because +4 dB measurably clips ~90s
  content. A test pins that the intro call NEVER passes `None`.
- **`intro_agree_labels.json`**: the server-side agree-label table, MIRRORED
  from the frontend `BUTTON_TRANSLATIONS` and pinned by a static parse-both-
  sides test -- closing the cross-surface-review observation from PR #584
  (two hand-maintained 18-language tables that could silently drift). Labels
  are data, not code: scar #6 keeps non-ASCII out of `.py`.
- **28 tests** (`backend/tests/unit/test_intro_route.py`): per-language sweep
  DERIVED from `SPOKEN_LANGUAGE_BCP47`, flag gate, unknown-form 400 with
  synthesis never invoked, English fallback, single-RPC cache pin, ETag/304,
  0 dB pin, 502 error-type-only, the frontend mirror pin, and
  `script_version` derivation. All six assertion families mutation-verified
  red-then-green.
- **Live smoke test** (1 real synthesis, ~5 cents): Spanish I-90 through the
  real route -- 200 audio/mpeg, 409KB via `es-US-Chirp3-HD-Algieba`; repeat
  served from cache in 16ms with a stable ETag; If-None-Match returned 304.
- **Routes table** in `docs/technical_guide.md`: added the intro row AND the
  previously-missing spell-back row (same enumeration, same fix); replaced
  the accumulated multi-bead stamp narrative with the canonical short stamp.
- **Filed**: an eval bead for the cold-synthesis latency finding (below);
  a design-input note appended to bead `s1iex.5`.

## Lessons

- **Cold synthesis of a full clip takes ~20 seconds** -- the plan's
  "multi-second cold-cache fetch" undersold it by an order of magnitude. The
  in-process cache dies with the Cloud Run instance (which scales to zero),
  so first users per instance wait ~20s. Bead `s1iex.5`'s loading/tap-to-play
  design must own that wait; a persistent (GCS-backed) clip cache is filed
  as its own eval bead rather than decided here.
- **When a table row you're adding sits next to a hole in the same set, fix
  the set** (scar #7 in miniature): the routes table had never listed
  `/api/tts/spellback`; adding only the intro row would have left the
  enumeration half-honest.
