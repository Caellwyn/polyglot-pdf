## Trigger

P3.0 of the schema-v2 epic `polyglot-pdf-h76m` (plan:
`~/.claude/plans/rustling-discovering-hearth.md`, maintainer-machine-local;
external-review adoption): the shape-normalization contract both TS islands
will evaluate through gets specified and vector-pinned as its OWN bead BEFORE
P3.1 changes any evaluator semantics -- discovering this contract inside the
two-evaluator bead is the wrong time.

## What shipped

- `normalizeToComposite.ts`, duplicated VERBATIM in
  `frontend/src/schema-forms/utils/` and `schema-editor/src/utils/` (no
  shared package by design -- the islands build independently). Fully
  self-contained (local structural types, zero imports) so the copies can be
  byte-identical; the editor runner ASSERTS byte-identity, so a drift-edit in
  one island turns CI red.
- The contract: null/undefined -> null ("always shown"); legacy single
  condition -> one-atom `all_of` group with the atom passed through UNTOUCHED
  (zero semantics -- no operator rewriting; the vq4m equals-membership hack
  stays in the leaf evaluators until P6.2; stray non-contract keys dropped);
  v2 group -> passthrough (empty buckets dropped, members must be atomic --
  depth <= 1); every malformed shape (mixed atom+bucket keys, nested groups,
  non-array buckets, non-object inputs, empty groups) -> null +
  `console.warn`, FAIL-OPEN, mirroring the runtime's unknown-operator
  fallback -- never throw on schema data.
- `shared/conditional-vectors.json` gains a 26-case `normalize` section
  (documented under a new `normalizeShape` key) run by BOTH existing vector
  runners; MALFORMED-* cases also assert the warn fires, clean cases assert
  it does not.
- The P3.0 property, in both runners: for every v0 vector,
  evaluate(normalize(show_if).all_of[0]) === evaluate(show_if) through
  TODAY'S evaluator -- normalize provably changes no behavior.
- No production path consumes the helper yet; the evaluators rewire through
  it in P3.1 (`polyglot-pdf-h76m.8`).
- Fresh-eyes triage (Sonnet, 1 round): GAPS-FOUND(0) -- both exit criteria
  PASS under live re-execution + 13 hand-written adversarial probes beyond
  the pinned vectors. Three nits, all adopted inline: journal case-count was
  off by one; two uncovered vector paths pinned (nested group via any_of;
  stray keys inside a bucket member); the property test gained a legacy-shape
  guard so a future composite-show_if vector fails clearly instead of
  crashing on .all_of[0]. Adopt 3 / reject 0 / defer 0; no beads filed.

## Lessons

- Byte-identity between deliberately-duplicated island files is cheap to pin
  in a test (walk up from cwd to the repo-root marker, readFileSync both) and
  is a much stronger guard than the comment "keep these in sync".
