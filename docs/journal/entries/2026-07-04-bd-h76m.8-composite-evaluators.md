## Lessons

- Widening a shared wire type (`show_if`) and letting tsc enumerate the
  breakage sites is a reliable consumer-inventory cross-check: it caught the
  editor FieldEditor UI and test-local evaluators the grep-based inventory
  had already flagged, and nothing more -- the two lists agreeing is the
  signal the inventory was complete.
- vitest's default fork pool flakes under parallel load on this Windows
  environment (one unrelated App.hosted test failed in a full run, passed in
  isolation and on a clean tree, passed full-suite on rerun);
  `--pool=threads` is the stable local invocation. CI (Linux) is unaffected.
