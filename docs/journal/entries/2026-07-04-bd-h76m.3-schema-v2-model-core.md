## Trigger

P1.1 of the schema-v2 epic `polyglot-pdf-h76m` (plan:
`~/.claude/plans/rustling-discovering-hearth.md`, maintainer-machine-local) --
the single center of gravity every later bead imports. The W-7 failure showed
the model layer carries three overlapping generations of group/conditional
machinery, cannot express "(A AND B) AND NOT C", and silently accepts the
real modeling failure (8 options all value="1") while only the invented
operators tripped validation.

## What shipped

- `backend/models/conditional_vocabulary.py` (new): the machine-readable v2
  vocabulary registry -- operator specs (value arity + trigger-type compat
  matrix + option-reference flag), choice/trigger type sets, the option-slug
  convention (`^[a-z0-9][a-z0-9_-]*$`) and deterministic slug minting
  (`mint_option_slug` / `mint_unique_slugs`). Import-free of form_models so
  the model can import it without a cycle; a cheap registry<->enum sync test
  guards drift until P1.2's contract test.
- `backend/models/form_models.py`: `FieldType.CHECKBOX_GROUP`;
  `ConditionalOperator.INCLUDES/NOT_INCLUDES`; `ConditionGroup`
  (all_of/any_of/none_of, flat by construction via extra=forbid + atomic
  bucket members); `show_if: Union[ConditionGroup, ConditionalDisplay]` and
  new `require_if` beside it; `FieldOption.pdf_on_value`;
  `iter_condition_atoms()` reader normalization; `schema_version` stamp with
  v2-gated strictness in a model_validator (checkbox=standalone-bool with
  options forbidden, options>=2, slug format, option-value uniqueness,
  per-option PDF fillability, operator/trigger compat, value arity,
  option-slug reference checks) -- every violation message carries
  `fields[i] (id=...)`; `controls_fields` raises DeprecationWarning under v2
  (still silent for v1 kits); `validate_all_references` now flattens
  composite + require_if conditions and warns on conditional cycles.
- `ConditionalDisplay.value` became Optional (needed for the no-value
  operators is_empty/is_not_empty/is_checked in v2 authoring; v1 kits all
  carry values so nothing changes for them).
- 42 tests in `backend/tests/test_form_models_v2.py`, incl. the is_checked
  DUAL-FATE shared fixture (`backend/tests/fixtures/is_checked_dual_fate.json`)
  that the P6.1 migration tests must also consume, per-rule violation

- Fresh-eyes triage (Sonnet, 2 rounds): round 1 GAPS-FOUND(3) -- (a) a

## Lessons

- The v2 strictness had to live at the SCHEMA level (model_validator on
  FormSchema), not field validators: per-field validators cannot see
  schema_version or resolve trigger fields, and the compat matrix is a
  cross-field rule by nature.
- `scripts/bakeoff/prior_extractor/` ships its own local `form_models.py`
  copy (`from form_models import ...`) -- a grep for model importers must
  exclude it before asserting blast radius.
