## Trigger

Gate 1 RECALL (jnjj.26) measured secretary feasibility on a SINGLE context format
(grouped-by-section), deferring a format bake-off. This bead runs that comparison:
which rendering of the form catalog best lets a cheap model BOTH reason across
fields AND ground answers in exact field ids?

## What shipped

- Two new renderers in `backend/scripts/secretary_context.py`: `render_flat_json`
  (flat JSON array of field objects -- max reference fidelity) and `render_prose`
  (markdown, one sentence/field -- max reasoning fluency), alongside the existing
  grouped-by-section. A `CONTEXT_FORMATS` registry + `render_context(..., fmt)`
  dispatcher.
- `probe_secretary_recall.py` gained `--format {grouped,flat,prose}` (artifacts
  tagged by format so runs don't collide) and `--model` (override knob). Also
  added retry-on-503 to the secretary call.
- Findings: `scripts/spikes/secretary_context_format_findings.md` + three artifacts
  `secretary_recall_{grouped,flat,prose}_*.meta.json`.

## Result: GROUPED-BY-SECTION wins -- baseline validated

Same 49-query battery + Sonnet judge, all on `gemini-3.1-flash-lite` (finalized
2026-06-27 set, on the section-fixed renderer):

| format | tokens | recall | precision | strict | synth_ok | disambig | halluc |
|---|---|---|---|---|---|---|---|
| **grouped** | 9,469 | **0.931** | **0.853** | **0.726** | **0.920** | **0.965** | 2 |
| flat | 13,271 | 0.913 | 0.830 | 0.691 | 0.904 | 0.948 | 1 |
| prose | 7,812 | 0.883 | 0.814 | 0.626 | 0.904 | 0.931 | 2 |

- **Grouped wins EVERY accuracy axis** (recall, precision, strict-match, synthesis,
  disambiguation). Recommended default (already the baseline -- the data validates
  the original choice).
- **Flat JSON is dominated:** +40% tokens for lower accuracy than grouped on every
  axis. It sits in the MIDDLE (beats prose) but pays the most tokens to do it. The
  reference-fidelity hypothesis didn't pay off. Rejected.
- **Prose is cheapest (-17% tokens)** but WEAKEST-or-tied on every accuracy metric
  (recall 0.883, precision 0.814, strict 0.626 lowest, synth 0.904 tied-with-flat,
  disambig 0.931). A conditional token-efficiency lever IF high-concurrency cost ever
  binds (the jnjj.41 regime); not the default now, where accuracy is the priority.
- Hallucination (grouped 2, flat 1, prose 2) / over-inclusion (4/5/5) -- within
  sampling noise, not format-driven (model/architecture properties, per jnjj.26).

## Process notes (the model + the flapping)

Measured on `gemini-3.1-flash-lite`, NOT the nominal `gemini-2.5-flash-lite`:
2.5-flash-lite has been in a sustained, widely-reported flapping/503 degradation
for days. Maintainer decision (2026-06-26): default the recall probe to
3.1-flash-lite for a stable, CONSISTENT measurement substrate -- a per-call
fallback was explicitly rejected here because mixing models mid-battery would muddy
a comparison (a comparison must hold the model constant). Production resilience (the
2.5->3.1 fallback) lives in `TextAIGemini` (jnjj.42, merged), where mixing across
calls is the correct behavior; the research probe wants consistency instead. Cost
of the switch is negligible (~2.5x on a <$1 trial).

Several measurement runs were lost to the machine sleeping mid-run (a suspended
background process holds a dead socket and stalls). Lesson: long judge-bound probe
runs are fragile to sleep; the final clean run completed by running the last format
in the FOREGROUND. The comparison is internally consistent (all 3 formats, one
model, one battery); RELATIVE ranking is sound. Absolute recall may differ slightly
from Gate 1's 2.5 numbers -- re-confirm on a healthy 2.5-flash-lite only if a
target-model absolute is needed; the format CHOICE does not hinge on it.
