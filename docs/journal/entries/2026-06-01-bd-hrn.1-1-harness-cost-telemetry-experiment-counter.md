## What shipped

A deterministic, **zero-model-token** telemetry script and the experiment-state
counter that drives the A/B phasing.

- **`scripts/harness_ledger.py`** parses the Claude Code session transcript
  JSONL and appends one row to `docs/journal/harness_ledger.jsonl`. The split
  that makes the experiment legible — **orchestrator vs subagent** — falls out
  of the transcript's `isSidechain` flag on each assistant turn; tokens are also
  bucketed **by model**, which is exactly the arm-B / Haiku-escalation signal
  (which model a session's subagents actually ran on). Cache-read and
  cache-creation tokens are tracked as separate fields from fresh input so a
  cross-arm cost comparison isn't distorted by cache behavior.
- **Mechanical vs judgment split.** The script auto-derives only what the
  transcript actually contains (token totals, per-model breakdown, wall-clock
  span, session id, turn counts). The numbers a script *cannot* read off a
  transcript — `--arm`, `--cost-category`, Copilot rounds, maintainer
  touchpoints, deferred-nit count, Haiku escalations, errors-shipped — are
  passed as flags by the orchestrator at closeout. This keeps it zero-token:
  no model turn is spent on parsing. Review/triage/fix *phase* token splits are
  an optional `--phase-tokens` JSON flag rather than a guess, because the
  transcript has no machine-readable phase boundary.
- **`cost_category` fairness rule** (`production` vs `audit`) is carried onto the
  row so measurement / cross-arm bug-reporting work can be bucketed `audit` and
  never charged to the arm doing it.
- **Transcript auto-discovery** derives `~/.claude/projects/<sanitized-cwd>/`
  (cwd with every non-alphanumeric char → `-`, verified against this repo's real
  dir name) and picks the newest `*.jsonl`. Because the dir is keyed by the
  **worktree** cwd, this is worktree-correct without any extra logic.
  `--transcript PATH` overrides for tests and ambiguous resumed sessions.
- **`.beads/experiment_state.json`** (seeded at zero, committed/tracked):
  `baseline_A` / `arm_B` / `arm_C` / `arm_BC` counts + a derived `phase`. The
  script bumps the right counter per `--arm` and prints the plan's next-phase
  directive (A≤15 → start B/C → independent-arms report → BC → final report).
  `--print-directive` reads it without writing anything.
- **Closeout Step 8.5** calls it (warn-only — a missing/failed row never blocks a
  merge); `settings.json` allowlists both invocation forms.
- **`tests/test_harness_ledger.py`**: 23 fixture-based tests covering the actor
  split, per-model breakdown, cache separation, malformed-line tolerance,
  cost_category, provenance, append, counter transitions + directives, cwd
  sanitization, discovery (newest-wins / missing-returns-None), and the
  end-to-end CLI (append+bump, `--no-counter`, `--dry-run`, missing-transcript
  exit 1, `--print-directive`).

Verified against the plan's checklist: ran `--dry-run` and a throwaway-ledger
end-to-end run against THIS session's real worktree transcript — discovery found
the live JSONL, parsed the orchestrator token totals, appended a row, and bumped
the counter (exit 0, no error on the worktree path). Full repo `tests/` suite:

**Fresh-eyes review (Sonnet) + Copilot round 1.** Copilot: CLEAN, no findings.
Fresh-eyes: 4 findings, **3 adopted / 1 rejected / 0 deferred**:
- *adopt* — tests didn't exercise `bump_experiment_state` setting `phase='BC'`
  or `'report'` (only `BC-toggle`); added two tests so a casing/string change in
  those branches is caught.
- *adopt* — `main()` accepted a missing `--arm` silently (row `arm=null`, counter
  un-bumped, no signal). Added a stderr WARNING rather than `required=True`,
  since `--no-counter` / audit re-runs legitimately omit `--arm`; added a CLI
  test pinning the warning + null row + untouched counter.
- *adopt* — Step 8.5 used `date -u +%FT%TZ`; `%F`/`%T` are GNU extensions, so
  BSD/macOS `date` would emit junk. Switched to the explicit
  `%Y-%m-%dT%H:%M:%SZ` form in the skill + the script's help text.
- *reject* — a "test masks the no-arm gap" note the reviewer itself concluded was
  structurally fine (the test passes `--arm A`, so no vacuous pass).

## Lessons

- **`isSidechain` is the orchestrator-vs-subagent boundary** in the transcript
  JSONL — the single field that makes "where did an arm save tokens" answerable.
  Any future transcript-parsing tool should key on it.
- **Python def-time default args don't honor a monkeypatched module global.**
  The script's functions take `path=MODULE_CONSTANT` defaults; `main()` must pass
  the *current* module-level path explicitly or a test's `monkeypatch.setattr`
  (and any runtime reassignment) is silently ignored. Caught while wiring the CLI
  tests; fixed by threading the paths through `main()`.
- **Closeout-supplied counters beat transcript-mined ones.** Resisting the urge to
  have the script infer Copilot rounds / phase from the transcript is what keeps
  it zero-token; the orchestrator already knows those numbers at closeout.
