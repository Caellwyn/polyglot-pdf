## Trigger

Two defects from the 2026-11-20 sim-user benchmark on `gemini-3.8-live`:
- **`r3ham.23`.** Once in 45 spellback deliveries, the model read the
  `delivered` tool response's prose aloud ("The user has ALREADY heard the
  stored spelling ... stay silent").
- **`r3ham.24`.** Wrong values were stored and confirmed. The phone-number
  case could not be diagnosed, because the run did not log what
  `update_form_fields` wrote.

## What shipped

- **`delivered` is a bare status.** The response is `{success, status:
  "delivered", user_has_been_asked: True, awaiting: "user_yes_or_no"}` with no
  message. The stay-silent rule already lived in `DTI_SPELLBACK_SI_ADDENDUM`,
  which gains one sentence scoped to this tool: "The name_spellback response
  is a status for you, never text to say: do not read it aloud."
- **Field writes logged.** Sim runs record per generation each
  `update_form_fields` write: the sent value, `success`, `applied_fields` and
  `stored_values`. That is synthetic persona data only.
- **One frugal validation run.** At the maintainer's request (validation
  about $1, not $20), this was a single W-7 self-correcting run capped at 24
  user turns, costing $0.62 (`scripts/spikes/r3ham_23_24_probe_findings.md`):
  - 4 deliveries, all silent, with no re-ask and 0 of 21 STT divergences;
  - 7 of 7 corrections re-stored correctly, 3 of them numeric.

  The long-session I-90 case moved to `r3ham.25`, which reads the next I-90
  run's write log at no dedicated spend.

## Lessons

- **A rule written to fix one tool must name that tool.** The first SI
  sentence said "a tool response is ... never text to say". The Opus pass
  caught that the stored-value echo ("Read THIS stored value back") and field
  guidance in other tool responses are meant to be voiced, and the addendum is
  the last and most authoritative SI text. The probe's read-backs still worked,
  but a probe that happens to pass is not a reason to keep a contradiction.
- **Size a validation run to its question.** Every spellback clip lands in
  the first ~18 user turns of a W-7, so `--max-user-turns` buys the same
  evidence for about a fifth of the cost. Sampling cannot prove a 1-in-45
  defect gone. Remove its cause, and spend only on checking for regressions.
- **`bd update --notes` replaces notes.** It wiped r3ham.24's two earlier
  wrong-value examples. They were restored from this session's record. Use
  `--append-notes`.
