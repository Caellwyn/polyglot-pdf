## What shipped

- `scripts/authoring/eval_extraction.py`: one command running
  `[extract ->] repair -> lint -> roundtrip -> score` over the benchmark set
  (w7, w7-2, f1040 + the held-out w9) and printing one summary table
  (verdict, lint E/W, value-convention %, roundtrip choice/text %, field F1,
  structural assertion, repair count). Exit 1 when any row is RED. Manual
  command, never per-PR CI (--extract runs the LLM per form; f1040 is >6 min
  + paid tokens). Default mode evaluates existing schemas: a --draft-dir, an
  explicit --form/--draft pair, or each kit's gold as a labeled baseline row.
  The repair step self-activates when P5.2 ships schema_repair.py (until
  then the column reads "-").
- Structural assertions -- the re-extraction regression anchor
  (`check_widget_coverage`): per-form widget groups that must survive
  extraction with identity intact. Every listed widget leaf claimed exactly
  once across fields/options, all claiming option values distinct. The check
  is deliberately MODELING-AGNOSTIC: it passes on today's gold shape (N
  standalone one-option checkboxes) AND on the v2 target (one consolidated
  checkbox_group), reporting which via a `consolidated` flag -- what it can
  never do is silently drop a box or accept collapsed identity. Pinned
  groups: w7/w7-2 reason boxes c1_2[0]..c1_9[0]; w9 classification
  c1_1[0..6] + c1_2[0].
- `scripts/schema_score.py --pdf`: the existing roundtrip_fill (bd 7a9.14)
  and the P2.1 schema_lint wired in as a first-class report section (c) --
  fill truth, value convention, lint counts + top findings.
- Held-out form: IRS W-9 (Rev. 3-2024) committed at `form-kits/w9-heldout/`
  with NOTE.md recording the selection-time flat-model fit check the plan
  requires: 7 classification checkboxes sharing base name c1_1 with DISTINCT
  on-values 1-7 (the true-AcroForm radio-kid pattern -- v2 pdf_on_value --
  complementing W-7's distinct-names/same-on-value pattern), one
  membership-gated LLC sub-field, one any_of-gated 3b box; no
  (A OR B) AND (C OR D) nesting anywhere. Deliberately NO schema.json (a
  schema would mean somebody tuned against it).

Exit criteria: (1) the archived broken W-7 draft scores RED on the
convention/lint columns -- PASS (11 lint errors, 0% value convention,
structural FAIL; pinned by test); (2) one command emits the multi-form table
incl. structural assertions -- PASS (test captures the table: 4 rows,
"PASS (8w, split)" markers, f1040 baseline correctly RED on its shipped
duplicate bug); (3) the held-out form is committed with the fit note -- PASS
(NOTE.md; a test asserts the form+note exist and no schema ever ships).

Suites: 1424 passed (backend + root harness, -m "not external").

Observation recorded for later phases: roundtrip_fill's choice% is
attempted-based, so a group whose options carry NO pdf mapping contributes
zero attempts and can read 100% on a broken draft -- the value-convention,
lint, and structural columns are the layers that catch that case (by
design); the verdict combines all of them.

## Lessons

- A regression anchor for a planned MIGRATION must be modeling-agnostic:
  pinning the v2 target shape would have made the assertion fail on today's
  gold (blocking the baseline table), while pinning today's shape would have
  failed the v2 future. Asserting the INVARIANT (widget identity coverage)
  instead of the representation lets one fixture span the transition.
- Percentage metrics with self-selected denominators (attempted-based fill
  rates) go green exactly when the input is most broken; pair them with a
  coverage-style check whose denominator is fixed by ground truth.
