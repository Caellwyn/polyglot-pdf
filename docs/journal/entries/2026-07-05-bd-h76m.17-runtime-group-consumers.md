## Trigger

consumers still dispatched on the v1 vocabulary only -- a v2 checkbox_group
reaching the PDF filler fell to the scalar path and printed BLANK, and the
voice-update validator skipped option-membership checks for the type
entirely. Filed as `polyglot-pdf-h76m.17`, dependency-wired to block P4.2

## Lessons

- PyMuPDF widget wrappers hold WEAK references to their page: `doc[0]
  .widgets()` with a transient page dies nondeterministically under GC
  (test-side), and `Widget.field_value =` on appearance-poor widgets does
  not persist `/V` without `update()`. For state writes the route cannot
  `update()` (XFA scar), so direct `xref_set_key` on V+AS is both the
  deterministic and the semantically-correct move.
- PyMuPDF cannot author standalone RADIOBUTTON widgets at all (its checker
  demands a Parent/Kids tree); synthetic same-name button groups are built
  from checkbox widgets + /T + /AP xref surgery.
