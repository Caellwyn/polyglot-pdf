## Trigger

G1 (bd polyglot-pdf-jnjj.5) is the keystone GO/NO-GO gate for Pillar B of the
SI-reduction epic (polyglot-pdf-jnjj). Pillar B's premise: delegate cross-field
contradiction checking (zip-vs-state, future-dated births, etc.) to a separate
cheap text model (`gemini-2.5-flash-lite`) reading client form state, SO THAT the
live voice model no longer has to carry the in-system-instruction ADDRESS
CONSISTENCY prose. Removing that prose authorizes deleting an incumbent safety
check -- so the epic gated it on a measured detection comparison. B3/B4/B5 (the
validator service, triggers, steering) and B1 (remove the SI prose) are all
blocked on this gate's verdict.

## What shipped

**A measurement and a NO-GO** -- plus a rescope signal for the whole B pillar.

Three arms scored blind on a labeled set of 80 cases (34 contradiction + 46
clean), each a contract-2 minimal client-state payload over REAL I-90
address/date fields:

| arm | recall | precision | FN | FP |
|---|---:|---:|---:|---:|
| in_si_check (incumbent, `gemini-2.5-flash` + verbatim in-SI prose) | 1.000 | 1.000 | 0 | 0 |
| flash_lite (proposed, `gemini-2.5-flash-lite` + dedicated prompt) | 0.735 | 1.000 | 9 | 0 |
| no_check (floor) | 0.000 | n/a | 34 | 0 |

**VERDICT: NO-GO.** The gate is "GO iff flash-lite recall >= in-SI check recall at
acceptable precision." flash_lite recall 0.735 < in_si 1.000 -> fails. Precision
is not the issue (flash_lite is perfect on the 46 clean cases, including the
territory / foreign-address / dual-address precision traps); recall is.
flash_lite missed ~1 in 4 contradictions the incumbent caught.

The miss is **concentrated**: 4 of 9 misses are the `state_country` class (US
state + foreign country, e.g. "New York" + "Canada") -- flash_lite returned an
empty conflict list 4/5 times despite an explicit prompt line for that class, so
it is at least partly a model-capability gap, not just wording. zip_state (the
canonical, most-common class) held up at 12/14.

**Consequence:** B1 (jnjj.13, remove the ADDRESS CONSISTENCY prose) is blocked by
this NO-GO -- the prose stays as the primary check. The flash-lite validator is
still useful as a SECOND, zero-false-positive defense-in-depth net at boundaries,
but it is an ADDITION to the in-SI check, not a REPLACEMENT. Pillar B's "so the
live model no longer carries the check" framing does not survive the gate; B
ships as belt-and-suspenders or is rescoped (a product-direction call surfaced to
the maintainer, not decided here).

## Lessons

- **Corpus provenance was stated, not fudged (the bead's first guard).** This is
  SYNTHETIC injection over real I-90 field structure, not real transcripts (the
  pre-pilot demo logs no field values, so there is nothing to mine). Synthetic
  cases are cleaner and more on-distribution than messy real sessions, so every
  recall number is an UPPER BOUND on real-world recall -- which makes a NO-GO
  STRONGER, not weaker: flash-lite already fell short on the easy set.
- **The fairness bias was removed where it could be and recorded where it
  couldn't (the bead's second guard).** Both live arms ran at the SAME boundary
  over the SAME full state, so the comparison isolates model+prompt skill, not
  who-saw-more-fields. The two residual biases (the in-SI proxy is text-only and
  misses the audio channel; production fires it per-field, not once at the
  boundary) BOTH favor GO -- and GO still failed, so the verdict is robust to them.
- **A measurement spike is a decision instrument: watch the per-class breakdown,
  not just the headline.** The headline (0.735 vs 1.000) says NO-GO; the per-class
  table says WHY (state_country collapse) and whether it's recoverable (partly
  promptable, but a prompt hand-tuned to a known failure set is itself a fragility
  signal). Same lesson the sibling G2 cost gate (jnjj.6) recorded: the secondary
  columns carry the actionable signal.
