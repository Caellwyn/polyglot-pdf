# DeepSeek V4-Flash as Automated PR Reviewer -- Research Notes

**Source:** Gemini research conversation, 2026-06-16
**Purpose:** Blueprint for trialing DeepSeek V4-Flash as an alternative/complement to Codex for automated PR review.

---

## Why DeepSeek V4-Flash

- Drop-in OpenAI-compatible SDK endpoint -- minimal integration cost.
- Automatic disk-based context caching: static system prompt cached across runs drops input cost by ~98% (to ~$0.0028/1M tokens).
- 1M token context window -- handles large diffs.
- `thinking` mode available for deeper algorithmic analysis.

---

## Integration Blueprint

### 1. API Setup

1. Generate key at the DeepSeek Developer Platform.
2. Store as GitHub Actions secret: `DEEPSEEK_API_KEY`.

### 2. Review Script (`scripts/review_pr_deepseek.py`)

Key design points:
- System prompt MUST be static across runs to trigger caching.
- Diff is the only dynamic content (goes in the user message).
- `temperature=0.2` for focused, analytical output.
- `thinking.type=enabled` for algorithmic debugging.

```python
import os
import sys
from openai import OpenAI

def main():
    api_key = os.environ.get("DEEPSEEK_API_KEY")
    pr_diff_file = os.environ.get("PR_DIFF_FILE", "diff.txt")

    if not api_key:
        print("Error: DEEPSEEK_API_KEY is not set.")
        sys.exit(1)

    try:
        with open(pr_diff_file, "r") as f:
            pr_diff = f.read()
    except FileNotFoundError:
        print(f"Error: Diff file {pr_diff_file} not found.")
        sys.exit(1)

    client = OpenAI(
        base_url="https://api.deepseek.com",
        api_key=api_key
    )

    # Keep this static to trigger context caching across PRs.
    system_prompt = (
        "You are an expert, adversarial Senior Code Reviewer. "
        "Your task is to review code modifications generated by an automated agent (Claude Code). "
        "Look specifically for blind spots Claude might have missed: subtle edge cases, "
        "concurrency/race conditions, optimization gaps, security/sanitization flaws, "
        "and architectural pattern adherence.\n\n"
        "Provide your review in clean Markdown. For bugs, reference the file and line block. "
        "If the code looks solid, reply with 'LGTM' and a quick encouraging summary."
    )

    print("Sending PR diff to DeepSeek V4-Flash...")

    response = client.chat.completions.create(
        model="deepseek-v4-flash",
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": f"Review the following PR patch diff:\n\n{pr_diff}"}
        ],
        temperature=0.2,
        extra_body={"thinking": {"type": "enabled"}}
    )

    review_output = response.choices[0].message.content

    print("\n=== DEEPSEEK REVIEW OUTPUT ===")
    print(review_output)

    with open("review.md", "w") as f:
        f.write(review_output)

    usage = response.usage
    if hasattr(usage, "prompt_cache_hit_tokens"):
        print(
            f"\n[Cache Status] Hits: {usage.prompt_cache_hit_tokens} tokens"
            f" | Misses: {usage.prompt_cache_miss_tokens} tokens"
        )

if __name__ == "__main__":
    main()
```

### 3. GitHub Actions Workflow (`.github/workflows/deepseek-review.yml`)

```yaml
name: DeepSeek V4-Flash Automated PR Review

on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write
      contents: read

    steps:
      - name: Checkout Code
        uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Install Dependencies
        run: pip install openai

      - name: Generate PR Patch Diff
        run: |
          git diff origin/${{ github.base_ref }}...HEAD > pr_diff.txt
          echo "PR_DIFF_FILE=pr_diff.txt" >> $GITHUB_ENV

      - name: Run DeepSeek Code Review
        env:
          DEEPSEEK_API_KEY: ${{ secrets.DEEPSEEK_API_KEY }}
        run: python scripts/review_pr_deepseek.py

      - name: Post Review Comment to PR
        uses: marooned/post-comment-action@v2
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          body_path: 'review.md'
```

## Integration Considerations for This Repo

- **Current reviewer: Codex** (`chatgpt-codex-connector[bot]`), triggered via `@codex review` comment per CLAUDE.md.
  DeepSeek would run as a *second* automated layer (parallel or in sequence), not a replacement.
- **Clean signal:** Codex clean = thumbs-up reaction. DeepSeek clean = "LGTM" in review body.
  The trial bead needs to define what "clean" looks like for `pr_review_watcher.py` integration
  (or run standalone without watcher integration initially).
- **Cache tip:** Keep `system_prompt` byte-identical across every PR run to hit the disk cache.
  Any change to the system prompt invalidates the cache.
- **High-volume scaling:** Pass `"user_id": "polyglot-pdf-ci"` in the API payload to get a dedicated
  scheduling lane on DeepSeek's side.
